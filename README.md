# Quiztr for Homebrew

[Quiztr](https://quiztr.com) turns your notes, slides or any topic into bite-sized quizzes.

```sh
brew install --cask quiztr/tap/quiztr
```

Quiztr for Mac needs macOS 15 or later on Apple silicon. The app updates itself, so `brew upgrade` leaves it alone
unless you run `brew upgrade --greedy`. Each release updates the cask here automatically.
